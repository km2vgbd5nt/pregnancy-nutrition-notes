# 【艾滋病防治宣传月】福建发布消除“艾梅乙”母婴传播项目 IP 形象

> 更新时间：2026-09-17 (UTC+8)

12月1日是第37个“世界艾滋病日”，今年的主题是“社会共治，终结艾滋，共享健康”。

12月1日

福建省2024年“世界艾滋病日”主题宣传活动

在福州启动

**消除“艾梅乙”母婴传播项目的 IP 形象**

**也正式对外发布**

据悉**，“艾梅乙”是艾滋病、梅毒、乙肝三种疾病的简称，这三种疾病皆会通过母婴渠道传播，使儿童遭受感染，直接给出生人口素质和儿童健康水平带来严峻威胁。**

但若能做到早检测、早诊断、早干预，并在医学专家的悉心指导下进行母婴阻断，“艾梅乙”母婴传播风险就能得到最大限度地降低，孕妈妈依然有机会生育出健康活泼的宝宝。

为深入贯彻落实国家卫生健康委印发的《消除艾滋病、梅毒和乙肝母婴传播行动计划（2022—2025年）》，支持国家向世界卫生组织申请消除艾滋病、梅毒和乙肝母婴传播认证，福建省卫生健康委员会等十三部门依照《福建省消除艾滋病、梅毒和乙肝母婴传播行动计划实施方案（2023—2025年）》等文件的内容及要求，**成立了福建省消除艾滋病、梅毒和乙肝母婴传播专项工作组，全力推动消除艾滋病、梅毒和乙肝母婴传播工作**。

为更好配合项目推广，**消除“艾梅乙”母婴传播的 IP 形象小艾米顺势而生**，并满心期盼成为孕妈妈和小宝宝们的忠诚守护者。

据介绍，“小艾米”名字中的“小”字源自“消”的谐音，“艾米”则取自艾滋病、梅毒、乙肝的拼音首字母 a、m、y，组合起来变为 Amy。Amy 的读音与“消除”的英文单词 eliminate 极为相近，于是小艾米有了肩负消除艾梅乙的神圣使命。
