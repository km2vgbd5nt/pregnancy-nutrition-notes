# 小儿肺炎的家庭护理

> 更新时间：2026-09-11 (UTC+8)

肺炎是指由各种不同病原体或其他因素所引起的肺部炎症。以发热、咳嗽、气促、呼吸困难为其主要临床表现。如果孩子患上肺炎后，除了药物治疗外，家庭护理对疾病的预后也起着至关重要的作用，父母应做好以下护理。

1. 环境：保持安静、整洁的环境，保证患儿休息。为保持空气流通，室内要经常定时通风。保持室内温度在18—22摄氏度，湿度为55—65%。

2. 饮食：肺炎患儿在患病期间需要足够的水分以及高热量、高蛋白、高维生素、易于消化吸收的食品。婴儿时期最好的食品是奶制品，此时切不可断奶，小儿愿意吃时不可十分限制。人工喂养的小儿可在牛奶中适当加些米汤，伴有腹泻时可用两份牛奶加一份米汤，如胃肠消化没问题，可用全奶。较大的患儿可取半流质食品，如稀饭、面片汤、麦片汤、鱼末、肉末、碎菜煲粥。食欲不好的患儿不要强迫进食，可多给流质食品、菜汤、果汁、鸡蛋汤等，以保证提供充足的水分和维生素；患儿肺炎痊愈后，适当给孩子增加高营养食物，以补足患病期间的营养缺失。

3. 保暖：东春季节气温较低，特别要注意保暖，但要适度。患儿发热时要松解衣服，以免散热困难，而出现高热惊厥，或引起出汗过多。汗多的患儿要及时更换潮湿的衣服，并用热毛巾把汗液擦干，这对皮肤散热及抵抗病菌有好处。

4. 发热的处理：1岁以内的患儿，在持续高热时，不要盖被，松开衣扣、系带。1—2个月的小儿用这种方法可以使体温下降；若无效，可用冰袋冷敷。较大的患儿可用美林、恬倩、泰诺等退热药物，剂量按医嘱执行，需第二次服用降温药物时，间隔时间不能小于4小时。期间鼓励患儿多喝水，尤其在发热时，应及时补足因高热而丢失的水分，同时也可以稀释痰液，有利于排除

5. 保持呼吸道通畅：小儿患肺炎时，肺泡内气体交换受到限制，体内有不同程度的缺氧，如果鼻腔阻塞或气管、支气管内有大量痰液，会影响空气的吸入而加重缺氧。因此家长要及时为患儿清除鼻内分泌物，鼓励孩子咳出痰液，在病情允许的情况下，家长应经常讲小儿抱起，五指并拢稍向内合掌成空心状，由下向上，由外向内的轻叩背部，边拍打边鼓励患儿咳嗽，以促使肺泡和呼吸道的分泌物借助于重力震动而易于排出。

肺炎的特点是，病情变化迅速，必须加强观察，及时发现严重情况，尽早到医院治疗。
